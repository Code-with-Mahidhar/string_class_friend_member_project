
# 🔤 String Class with Friend & Member Functions

## 📖 Overview
This project implements a **custom String class in C++** using Object-Oriented Programming concepts.  
It demonstrates how string operations can be performed using **member functions and friend functions** without relying on built-in string libraries.

---

## 🚀 Features
- Custom string implementation using class  
- Use of **member functions**  
- Use of **friend function**  
- Core string operations:
  - Input & Output  
  - Length calculation  
  - Concatenation  
- Demonstrates encapsulation and OOP principles  

---

## 🛠️ Technologies Used
- C++ Programming  
- Object-Oriented Programming (OOP)

## ⚙️ How It Works
The program uses a **class-based approach** where:
- String data is stored inside a class  
- Member functions perform operations on strings  
- A friend function accesses private data for additional operations
